Know what it does.

Is this a Codex router?

Subrouter handles authentication and requests. This project connects that account pool to CodexBar and adds optional local routing controls. It does not replace either upstream project.

Does this show ChatGPT message limits?

It shows Codex subscription quota returned by Subrouter, including base short-window and weekly limits. It is not a general ChatGPT message counter.

Can it move my existing conversation?

No. A manual selection changes the default for new chats. Existing conversations retain their assignments. Seamless quota-exhaustion failover is not guaranteed.

Does it support Claude, Antigravity or widgets?

Claude and Antigravity remain separate CodexBar providers. Router-account widgets are not implemented by this integration.

What has been checked?

The native integration was built and installed locally. Quota-window accessibility actions were exercised. Ordinary pointer and light/dark pixel-level acceptance remain unverified. Full details are in the integration notes.
