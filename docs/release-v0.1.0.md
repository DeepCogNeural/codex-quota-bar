# Codex Quota Bar v0.1.0 — experimental

View multiple Subrouter Codex accounts in an existing macOS menu bar app.

- One local JavaScript provider, with no extra background service.
- Separate remaining quota and reset estimates for each account.
- Local aliases and authentication state indicators.
- No OAuth file access or model requests by the plugin.
- English and Chinese installation docs; concise agent-readable usage guidance.

Requires an existing Subrouter on port 31415 and CodexBar's local plugin support. Local acceptance used CodexBar 0.56.7 and Subrouter 0.1.130.

Download subrouter.js and install from CodexBar Settings → Plugins. Review and approve the local origin. Do not import another user's configuration.

Known limitations: experimental; no router-account Widget, no manual/automatic routing controls, no cross-provider handoff, no pixel-level UI check. See README.md and docs/validation.md before use.
